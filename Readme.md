# Practice **"Complete SQL and Databases Bootcamp"**

I’ve written for practice, experimentation, and learning.  
It covers a variety of topics including schema design, queries, joins, aggregations, indexing, and optimization.

---

## 📂 Structure

- `basics/` → Introductory queries (SELECT, INSERT, UPDATE, DELETE)
- `joins/` → Examples of INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN
- `aggregations/` → GROUP BY, HAVING, aggregate functions (COUNT, SUM, AVG, MAX, MIN)
- `indexes/` → Scripts demonstrating indexing and performance improvements
- `advanced/` → Stored procedures, triggers, views, transactions
- `practice_problems/` → SQL challenges and solutions

---

## 🚀 How to Use

### SQLite

```bash
 sqlite3 mydatabase.db < file.sql
```

MySQL

```bash
 mysql -u username -p database_name < file.sql
```

PostgreSQL

```bash
 psql -U username -d database_name -f file.sql
Replace file.sql with the script you want to run.
```
